locked mutation services still revalidate current membership, assignment, state,
latest submission and self-review. A true hint does not validate draft content.

Frontend consumes required booleans, uses native Submit/Review/edit/delete
forms and confirms success only from the server. It refreshes scoped Task,
collaboration and personal Notification queries; edit/delete cancels older GETs
and replaces/redacts all cached Comment copies. No optimistic completion,
automatic mutation retry, upload/storage or new workflow is added. Deliverable
detail/update/delete/upload still has no separate endpoint; inspect list rows
and submit a new revision through the existing lifecycle instead.
