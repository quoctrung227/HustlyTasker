# Database Rule

Repository-wide instructions are maintained in root `AGENTS.md`. Always read
that file and `documentation/HANDOVER.md` before using this historical database
checklist.


Before creating Django models:

1. Read DATABASE_SCHEMA.md.
2. Confirm relationship.
3. Confirm business rule.
4. Then create migration.


Do not create random fields without documentation.

Do not rewrite architecture without approval.

Always check existing documentation before modifying code.

Explain commands step-by-step.

Developer is not an advanced Django developer.
